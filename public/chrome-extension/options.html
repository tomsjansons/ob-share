ob-share Settings

Configure your ob-share browser extension

Server URL

The URL of your ob-share instance. Leave empty to use the default.

Default Share Mode

Choose what happens when you click the extension icon or use "Share this page". You can always override this using the explicit menu options.

How to Use

Click extension icon
Share using your default mode (URL only or full page capture)
Right-click on page
Access "Share this page", "Share with note...", explicit mode options, and "Settings"
Share URL only
Always share just the URL, regardless of default mode
Capture full page content
Always capture full page, regardless of default mode. Use this for authenticated pages!
Right-click on a link
Share that specific link to ob-share
Select text + right-click
Share the page with selected text as a note
